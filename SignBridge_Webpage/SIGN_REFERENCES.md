# Sign reference illustrations

Source: https://commons.wikimedia.org/wiki/File:Asl_alphabet_gallaudet.svg

ASL alphabet and digits by Darren Stone (Ds13), derived from David Rakowski's Gallaudet-TT font; vectorised by Marnanel. Wikimedia Commons lists the artwork as public domain. Retrieved 2026-09-16.

Adaptation: individual sign groups extracted from the SVG, printed character labels removed, framing adjusted. Hand shapes and motion arrows preserved. SVGs are embedded in index.html; no external image request is required.

J and Z require motion; static model predictions cannot validate their movement. Digits are learning references only; the current classifier has A–Z classes. Number palm orientation varies with context; see https://www.lifeprint.com/asl101/pages-signs/n/numbers1-10.htm .
